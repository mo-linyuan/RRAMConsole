### RISCV处理中断实例（供FPGA参考）

1.  main函数触发中断后到处理中断的handler
    
    ```c
    int main(void)
    {   
       //....
    
        // inital CIM interrupt
        returnCode = ECLIC_Register_IRQ(CIM_IRQn, ECLIC_NON_VECTOR_INTERRUPT,ECLIC_LEVEL_TRIGGER, 0, 0, eclic_CIM_handler);
    
        // Enable interrupts in general.
        __enable_irq();
    
        return 0;
    }
    ```
    
2.  确认中断源头，通过给地址为0寄存器的写0，消除中断。
    

```c
void eclic_CIM_handler(void)
{   
    printf("Enter CIM Interrupt\n");
    uint32_t interrupt_info;
    interrupt_info=NOC_icb_REG(2<<2);
    // printf("Interrupt Info: %x\n", NOC_icb_REG(2<<2));
    printf("Interrupt Info: %x\n", interrupt_info);

    NOC_00_REG(0<<2)=0x80000000;
    
    printf("Interrupt Complete\n");
    interrupt_info=NOC_icb_REG(2<<2);
    printf("Interrupt Info: %x\n", interrupt_info);
    NOC_offchip3(0<<2)=interrupt_info;

}
```

### 包头具体参数

VC：虚通道保留，暂未使用

RGN：目标区域，0为NOC 加速核区，1为riscv 拓展区

TYPE：PKG类型

| TYPE\[3\] | TYPE\[2\] |  |  |
| --- | --- | --- | --- |
| 0 | 0 | READ |  |
| 0 | 1 | Write |  |
| 1 | 0 | send out |  |
| 1 | 1 | SKP |  |

| TYPE\[1\] | TYPE\[0\] |  |  |
| --- | --- | --- | --- |
| 0 | 0 | Core Reg |  |
| 0 | 1 | Inst Sram |  |
| 1 | 0 | Data Sram |  |

## 指令集相关

16条32位的指令。

![instv0.svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/1298d33b-ecec-4017-980a-6ca80f30b0ee.svg)

### 1 控制类指令

如下是用于数据加载、rram写值、控制相关的指令。

#### LOAD

通过直接起始地址加载64位（double word）数据到指定index的buffer中，通过mask选择具体哪几个byte进行加载。

把 mem 的值 load 到 pre load buffer 里。

64位 = 8个值，一个值8bits。BUFFER INDEX(选PE) 是pre load buffer，每组PE都对应有一个，共8个。MEMORY ADDRESS是data SRAM的地址 不需要加base地址。BYTE MASK是标记mem地址里后面的一组值（8个值）中加载哪8个值。

![wavedrom (1).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/76319471-0a55-40f6-a8b2-379b5319a6a7.svg)

#### LOADB

把 mem 的值 load 到 pre load buffer 里。

通过计算出的起始地址_（offset+source base address）_加载数据到指定的buffer中，通过mask选择具体哪几个byte进行加载，基于buffer起始地址参数控制数据加载对齐的位置。

BUFFER INDEX 是pre load buffer，每组PE都对应有一个，共8个。也是加载64位，BYTE MASK是标记mem地址里后面的一组值（8个值）中加载哪8个值。

![wavedrom (2).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/437321f7-bb4f-4463-9438-6ed5207d0378.svg)

#### STORE

把result buffer 的值 store 到 SRAM 里。

将计算数据以64位（double word）64位 = 8个值 从结果buffer（PE INDEX，每组PE都对应有一个 result buffer，共8个。 ）回写到计算出的目标地址_（offset+source destination address）_。非所有计算指令都需要使用这一指令进行数据写回，仅进行累加的指令需要。TYPE暂时为空。

![wavedrom (3).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/67059862-d162-4bbf-b78a-de5ffd549ea0.svg)

#### CONFIG

通过直接目标寄存器地址将参数设置到配置寄存器中。每个核刚开始需要配置。

操作类型选择4' b0111为上半字; 4' b0011为下半字; 4' b0110为高位字节；4' b0110为上部低位字节; 4' b0010为下部高位字节; 4' b0001为下部低位字节。

SC为选择寄存器区域，0为计算核，1为网络接口（NI）。

![wavedrom (17).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/57ad60be-2c0f-4158-a400-386fff2b82d8.svg)

#### WRITEB

给rram写权重时（cell），写1比特

通过Pelement索引、rram索引和rram全地址在特定rram单元上进行操作。_单指令写1比特。_

操作类型(TYPE)选择: 0用于写入0等于复位；1用于write1等于set。

PE INDEX，每组PE的index，共8个，选择pe。 RRAM  INDEX ，选择pe里的哪几个rram阵列，RRAM FULL ADRESS 是rram 的坐标 行和列。

![wavedrom (5).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/df97b8b9-5e4e-4546-8498-24a28a381edd.svg)

#### WRITED

将sram上的值写到rram上，一次写64个。

通过计算出的起始地址_（offset+source base address）_，基于Pelement索引、rram索引和rram写入地址信息在特定rram行的一部分写入数据。_单指令写64比特。_

rram部分地址包含行数，以及左右半边区域的地址，0为左边，1为右边。（RRAM HALF ADRESS 是RRAM的行，单指令写64个，rram阵列是128，所以rram地址还包括左右半边区域的地址， 来要确定是某行的64个还是后64个）

![wavedrom (6).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/9af1f45f-0aad-4cfd-b2f3-0b66b5f69b54.svg)

#### READ

通过直接地址从内存sram中或rram中读取数据，然后将其发送到芯片外。_当前版本为发送到NoC上进行路由。_

ADDRESS 如果是sram的，PE 和RRAM INDEX 就不需要。

ADDRESS 如果是rram的，就是rram的地址，PE 和RRAM INDEX 都需要。

读取数据是:单次发送1个地址 

![wavedrom (7).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/29b6929e-2c1e-4082-aabc-508ad0607deb.svg)

#### CTRL 

其他操作

由不同的操作类型定义控制指令的作用: 4' b0000用于清除累积缓冲区; 4' b0001用于移位缓冲区; 4' b0010用于pc跳转；4' b0011做skip等于插入气泡。

### 2 计算类指令

如下是用于矩阵计算相关的指令。

**{V, VA}MUL{A}**，MUL为主体，每个指令都有的。{V, VA}和{A}为前缀和后缀，V表示Vecoter，对应多个Pelement同时输入多条向量，VA表示Vector aggregated，对应输入向量聚合后得的数值，{A}表示accumulated，对应结果数据需要累加。

{I} 表示不从 pre load Buffer里读数据，从SRAM里读数据

BYTE MASK 是多选，0101， INDEX是单选，唯一，是地址。

_**共性特点：**_

++_BYTE MASK用于选择始能的输入数据，等价于控制PE中对应阵列的开启情况。PE中所有的阵列都开启同一行进行计算。_++

#### MUL 

pre load Buffer里的数据 和 RRAM 进行 计算 结果存到 SRAM

将预加载到预载单元中的数据输入到指定Pelement的特定rram行上进行计算，然后将结果直接按计算出的目标地址_（offset+source destination address）_存回数据。

用BYTE MASK选择 pre load buffer 的组别序号 （共8个 ，这个组别与PE里的rram 对应），与 指定Pelement（PE INDEX）的对应的rram 进行计算， RRAM输入的行（RRAM HALF ADDRESS），计算结果存到SRAM的目标地址。（RRAM输出的列在寄存器里配置）

![wavedrom (9).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/80d8ae30-4865-4ff7-a80d-25765ee9d9dd.svg)

#### MULI 

SRAM 里的数据 和 RRAM 进行 计算 结果存到 SRAM

将存储在数据存储器中的数据直接输入到指定Pelement的特定rram行上进行计算，数据取值地址为计算出的起始地址_（offset+source base address）_，然后将结果直接按计算出的目标地址_（offset+ destination base address）_存回数据。

将SRAM里的一组数据(最多8个，64位，1-8个数据  BYTE MASK ）（地址= 读base+MEMORY） 与 指定Pelement（PE INDEX）的BYTE MASK对应的rram特定的 行 （RRAM输入的行=RRAM HALF ADDRESS）（RRAM输出的列在寄存器里配置）进行计算，计算结果，存到SRAM的目标地址（地址 = 写base+MEMORY）。

![wavedrom (11).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/a1b1743e-5af4-44ce-b102-d9635cfb44f9.svg)

#### MULA

preload BUFFER 里的数据 和 RRAM 进行 计算 结果累加到 Result Buffer。

将预加载到预载单元中的数据输入到指定Pelement的特定rram行上进行计算，结果数据存储在结果buffer中，可以进行多轮累积，不会直接存储，需要搭配LOAD指令使用。

用BYTE MASK选择 pre load buffer 的组别序号 （共8个 ，这个组别与PE里的rram 对应） 与 指指定Pelement（PE INDEX）的所有rram特定的 行 （RRAM输入的行=RRAM HALF ADDRESS）（RRAM输出的列在寄存器里配置）进行计算，计算结果累加(A)存到对应的 Result Buffer 里。如果需要把Result Buffer的数据移到SRAM，使用LOAD指令。

![wavedrom (10).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/5690ddae-2783-48b6-8add-0357963df5b1.svg)

#### MULAI

SRAM 里的数据 和 RRAM 进行 计算 结果累加到 Result Buffer。

将存储在数据存储器中的数据直接输入到指定Pelement的特定rram行上进行计算，数据取值地址为计算出的起始地址_（offset+source base address）_，结果数据存储在结果buffer中，可以进行多轮累积，不会直接存储，需要搭配LOAD指令使用。

将SRAM地址(MEMORY ADDRESS OFFSET)里的一组数据(64？8bits, 1-8个数据  BYTE MASK ）  与 指定Pelement（PE INDEX）的BYTE MASK对应的rram特定的行（RRAM输入的行=RRAM HALF ADDRESS）（RRAM输出的列在寄存器里配置）进行计算，累加存到对应的 Result Buffer 里。如果需要把Result Buffer的数据移到SRAM，使用LOAD指令。

![wavedrom (12).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/b818c66b-d16d-49cc-9b21-0f81e118b375.svg)

#### VMULA

将preload BUFFER 里的数据 和 多个PE的 RRAM 进行 计算 结果累加到 Result Buffer。

将预加载到预载单元中的数据输入到由mask控制的指定一个或多个Pelement的特定rram行上进行计算，结果数据存储在结果buffer中，可以进行多轮累积，不会直接存储，需要搭配LOAD指令使用。

用BYTE MASK选择 pre load buffer 的组别序号 （共8个 ，这个组别与PE里的rram 对应）(里有8组寄存器组，每组里有8个byte = 64 bits = 8value) 与 指定一个或多个Pelement（PE MASK）的所选rram阵列（BYTE MASK）特定的行（RRAM输入的行=RRAM HALF ADDRESS）（RRAM输出的列在寄存器里配置）进行计算，计算结果，累加存到对应的 Result Buffer 里。如果需要把Result Buffer的数据移到SRAM，使用LOAD指令。

![wavedrom (14).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/ac780642-cddd-49bf-826b-50789f818bf3.svg)

#### VAMUL 

preload BUFFER里的数据 聚合 与rram 计算，存到sram里。

将预加载到预载单元中的数据通过数据预处理单元聚合后的数值输入到指定Pelement的特定rram行上进行计算，然后将结果直接按计算出的目标地址_（offset+source destination address）_存回数据。

用BYTE MASK选择 pre load buffer 的组别序号 （共8个 ，这个组别与PE里的rram 对应）++的值聚合 聚合成一组值（对应byte mask）， 与++ 指定Pelement（PE INDEX）的所选rram（BYTE MASK）特定的行（RRAM输入的行=RRAM HALF ADDRESS）（RRAM输出的列在寄存器里配置）进行计算，计算结果存到SRAM地址(MEMORY ADDRESS OFFSET)里

![wavedrom (15).svg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O851mMwb4wl9V/img/3de5caae-3089-4ac0-b702-49eb11aa998b.svg)

#### VAMULA

preload BUFFER里的数据 聚合 与rram 计算，累加存到Result Buffer里。

将预加载到预载单元中的数据通过数据预处理单元聚合后的数值输入到指定Pelement的特定rram行上进行计算，结果数据存储在结果buffer中，可以进行多轮累积，不会直接存储，需要搭配LOAD指令使用。
