## 再验证 FPGA 到芯片

1. `top/sys_top.sv:71-72` 将 `sys_rst_n` 与 `por_rst_n` 固定为1，不产生低有效复位脉冲。需核对完整芯片上电/复位规范；不能随意假设脉冲时长、顺序或 boot_mode 电平。
2. `common_reg/common_reg.sv` 通过10级移位寄存器展宽 NoC Valid，没有使用 Ready 结束事务。若芯片按每周期 Valid && Ready 接受，会有重复接收风险。需用 ILA/逻辑分析确认一次命令的实际接受次数及数据稳定性。
